# Fruit Ripeness Classification Using Deep Learning

## Project Overview
A team research project comparing nine deep learning architectures for classifying tomatoes into three ripeness categories: unripe, ripe, and overripe.

## Models Evaluated
- Three custom CNN architectures
- AlexNet
- DenseNet201
- InceptionResNetV2
- ViT-B/32
- DeiT-Small
- Swin Transformer Tiny

## Results
- **DenseNet201:** 94.2% accuracy
- **InceptionResNetV2:** 91.2% accuracy
- **ViT-B/32:** 75.1% accuracy

## Techniques
Image preprocessing, data augmentation, deep learning model training, and performance evaluation using accuracy, precision, recall, F1-score, and confusion matrices.

## Key Finding
CNN architectures outperformed transformer architectures on the dataset used in this study, highlighting the importance of selecting models based on dataset characteristics.
